# 考研数学真题速查（独立数学站）

2010–2026 年考研数学（数一 / 数二 / 数三）真题的速查网页：按年份、科目、难度筛选题目，标记关键题，维护错题本，并可直接查看对应年份的原卷与解析 PDF。

纯静态站点，无构建步骤、无后端依赖。

> 线上地址：<https://math.feikntn111.us.ci>
>
> 这是**只含数学**的独立站。整套考研资料（数学 / 英语 / 政治 / 知识库）的主站在同级目录 `../kaoyan-hub/`，其中 `/math/` 就是本站内容迁进去的版本。两边共用同一套 `app.js` / `data*.js` / `meta*.js`，差别只在路径（本站相对路径，主站绝对路径）和顶栏。

## 功能

- **年份切换**：2010–2026，每年三科数据齐全才显示
- **科目切换**：数一 / 数二 / 数三
- **难度筛选**：常规 / 中档 / 难题 / 全部
- **关键题**：一键只看标记为重点的题目
- **错题本**：标记错题，数据存 `localStorage`（`file://` 下同样可用）
- **成绩记录**：按年份、科目记录自己的分数；选填可一键补齐未标记的题为做对，解答题可一键补齐未填写的题为满分，已有分数不会被覆盖，之后还能逐题修改
- **得分卡收起**：右下角实时得分卡的右上角有箭头，点一下收起成一条只显示总分的小胶囊（手机窄屏默认收起），选择会被记住
- **整卷「做完了」提示**：年份条右端的「进度」按钮点一下才展开（默认收起、不占位置），展开后显示当前这一卷做完没有（还没做完会写还差几题），右边是这一科的进度——已完成几年、还剩哪几年。整卷每一题都记过就自动算做完，也可以在纸上做完后自己点勾（`kaoyanMath.yearDone.v1` 只存手动改过的年份，没有记录时按分数自动判断；展开状态记在 `kaoyanMath.yearProgOpen.v1`）
- **年份按钮上的完成态**：每个年份按钮下面一行小字——做完了显示 ✓，没做完直接写还差几题；切板块、改分数、勾选都会即时重画
- **同题自动同步**：数一 / 数二 / 数三里题干相同或仅有细微措辞差异的题，在任一科改了分数，其他科的同一道题会自动跟着改
- **计时器**：选填 / 大题分开计时，可点开放大，分时同样按题号在同年各卷间同步
- **同题标签**：题干与同年其他试卷重复时，在题号旁标出各卷题号（如 数一3 · 数二2 · 数三4），悬停可看完整说明
- **模拟卷记录**：自定义模拟卷名称与科目，按 2021 年后的 150 分结构（10 选择 + 6 填空 + 6 解答）记录分数，单独汇总平均分、最高分及各模块得分
- **成绩统计**：按科目汇总总分、选择、填空、选填、大题、高数、线代、概率的均分与得分率；因 2021 年改革前后题型分值不同，各项均分按 21 年前 / 21 年起分段统计。卡片下面是一张逐年分数表（年份 / 选择 / 填空 / 大题 / 总分，每格「得分 / 满分」），没记完的题型显示「—」和已记题数
- **公式渲染**：KaTeX（本站通过 CDN 加载，首次打开需联网）
- **原卷对照**：题目卡片可打开对应年份的真题 / 解析 PDF
- **题型自动适配**：2021 年改革前后（8+6+9 与 10+6+6）分别呈现

## 目录结构

```
index.html        页面骨架与样式
app.js            渲染与交互逻辑
data.js           汇总入口 + 年份清单 + 按年懒加载器
dataYYYY.js       各年份题库（题目、考点、难度、答案要点）
metaYYYY.js       各年份元信息（试卷结构、分值）
pdfs/YYYY/        真题与解析 PDF（已压缩，每年 m1/m2/m3 的 paper 与 sol，部分年份含 review）
pdfs/supplement/  补充题（数一补充试卷与解析）
figs/             题目配图
wrangler.jsonc    Cloudflare Workers 静态资源配置
```

`pdfs/` 约 220 MB，随仓库提交。体积更大的高清未压缩原卷不在这里，见
<https://github.com/3456038583-gif/kaoyan-math-site-hd>（Release 里有打包下载）。

## 本地运行

直接打开 `index.html` 即可。若想避免个别浏览器的本地文件限制，也可以起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 部署

```bash
cd ~/File_no_iCloud/kaoyan-website/kaoyan-math-standalone
NODE_OPTIONS=--dns-result-order=ipv4first npx wrangler@latest deploy
```

Worker 名沿用历史值 `kaoyan-math-site`（改名会新建 Worker 并和自定义域名冲突）。
