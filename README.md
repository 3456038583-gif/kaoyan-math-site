# 考研数学真题速查（独立数学站）

2010–2026 年考研数学（数一 / 数二 / 数三）历年真题 + **61 套 2027 考研数学预测模拟卷（1,342 题）**的纯静态刷题与速查站点：支持逐题 LaTeX 还原、按年份/科目/难度/套系筛选、考场防剧透模式、单题个人笔记、错题本、计时判分与原卷/解析 PDF 在线翻阅。

纯静态站点，无构建步骤、无后端依赖，KaTeX 已本地化部署。

> 线上地址：<https://math.feikntn111.us.ci>
>
> 这是**只含数学**的独立站。整套考研资料（数学 / 英语 / 政治 / 词汇 / 知识库 / macOS 桌面版）的主站在 [kaoyan-hub](https://github.com/3456038583-gif/kaoyan-hub)（<https://kaoyan.feikntn111.us.ci>），两边共用同一套 `app.js` / `data*.js` / `meta*.js` / `mockdata.js` / `theme.css` / `countdown.js`。

## 核心功能

### 题库与模拟卷
- **历年真题（2010–2026）**：数一 / 数二 / 数三 17 年完整收录，自动适配 2021 年改革前后题型分值（8+6+9 与 10+6+6），附 B 站「小崔说数」逐题定位视频入口。
- **61 套 2027 成套模拟卷（共 1,342 题，27,944 段 KaTeX 公式 0 报错）**：
  - 李林六套卷（数一/二/三，18 套） & 李林四套卷（数一/二，8 套，含勘误修正）
  - 张宇八套卷（数一，8 套） & 张宇四套卷（数一/二/三，12 套）
  - 崔命六套卷（卷一至卷五 × 数一/二/三，15 套）
  - 支持**按套系胶囊筛选**与**只看未做**过滤，共用真题的计时、判分、错题本与成绩统计逻辑；全站解析已统一清理 `方法一 / 方法二 / 【注】` 分段排版。
- **补充真题 & 重点题**：数一 / 数二 / 数三 17 年补充真题对照表（复用真题题库 + 配套做题本/解析 PDF），以及一键筛选「重点题」。

### 刷题体验与效率工具
- **考场防剧透模式（`🎯 考场防剧透`，快捷键 `E`）**：一键隐藏考点、难度星级、重点标签与同题提示，模拟真实考场盲刷。
- **一键展开 / 收起全部解析** + **题号快速定位条（1–22）**：一眼看出已标错题与已记笔记的题目，点击平滑跳转。
- **单题个人笔记**：每题下方「笔记」抽屉支持记录易错点、二级结论与思路，自动保存至 `localStorage['kaoyanMath.notes.v1']`。
- **单题复制（保留 LaTeX）& 复制题图**：方便直接贴给 AI 辅助答疑或整理笔记。
- **键盘快捷键**：`J` / `K` 上下一题快速切换，`E` 切换考场防剧透，`⌘K` / `Ctrl+K` 打开快捷命令面板。
- **计时、判分与统计**：四档计时器（整卷 / 选填 / 大题合计 / 单题）、同题跨卷自动同步分数、可收起浮动得分卡、年份完成态追踪与 2021 改革前后分段均分统计。

### 全站多主题与全局组件
- **6 套界面主题**（顶栏「外观」一键切换，同步零首帧闪烁）：经典纸感、**液态玻璃（Liquid Glass 亮/暗）**、静谧深色、护眼青笺、水墨宣纸 + 3 档阅读字号调节。
- **专注番茄钟 / 180 分全真模考计时器**：内嵌在顶部倒计时栏右侧，跨页保持运行，结束带柔和提示音。

## 目录结构

```
index.html        页面骨架与样式
app.js            渲染与交互逻辑
theme.css         6 套主题引擎（含 Liquid Glass）与全局组件样式
countdown.js      倒计时栏 + 外观切换 + 专注计时器 + ⌘K 命令面板
data.js           真题入口 + 年份清单 + 按年懒加载器
dataYYYY.js       各年份真题题库
metaYYYY.js       各年份元信息（试卷结构、分值、重点题）
mockdata.js       61 套 2027 模拟卷题库（1,342 题）
supp.js           数一/二/三补充真题对照表
keymap.js         各年份重点题/补充真题完成态索引
pdfs/             真题、补充真题与模拟卷 PDF（压缩版）
figs/             题目与解析配图
vendor/katex/     本地 KaTeX
wrangler.jsonc    Cloudflare Workers 静态资源配置
```

体积更大的高清未压缩原卷见 <https://github.com/3456038583-gif/kaoyan-math-site-hd>（Releases 提供打包下载）。

## 本地运行与部署

```bash
# 本地预览
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000

# 部署到 Cloudflare（Worker 名沿用历史值 kaoyan-math-site，勿改）
cd ~/File_no_iCloud/kaoyan-website/kaoyan-math-standalone
NODE_OPTIONS=--dns-result-order=ipv4first npx wrangler@latest deploy
```
